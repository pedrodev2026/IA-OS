# Changelog - IA-OS v0.1.0-alpha.1

**Data:** 04 de Novembro de 2026  
**Status:** Em Desenvolvimento / Validação Inicial  

---

## Destaques da Versão

Esta é a primeira versão embrionária do **IA-OS**, focada no bootstraping bare-metal, integração do protocolo de boot Limine e validação de saída visual gráfica em UEFI x86_64.

### Adições e Modificações

#### 1. Estrutura do Projeto e Configuração do Cargo
- Inicialização do manifesto `Cargo.toml` com metadados do projeto sob licença `Apache-2.0`.
- Criação de `.cargo/config.toml` fixando o target `x86_64-unknown-none` e definindo parâmetros bare-metal:
  - `panic = "abort"` para suprimir stack unwinding sem runtime C++.
  - Flags de compilação sem Red Zone (`-C no-redzone=y`) para integridade de interrupções x86_64.
  - Modelo de código de kernel (`-C code-model=kernel`).
- Criação de `rust-toolchain.toml` travando o canal e habilitando `rust-src`.

#### 2. Protocolo de Boot Limine
- Integração da crate oficial `limine`.
- Declaração estática de `FramebufferRequest` com tags compatíveis com o protocolo Limine v5+.
- Configuração de `limine.conf` especificando menu de boot, timeout de 3 segundos e localização do binário do kernel ELF.

#### 3. Kernel Inicial (`src/main.rs`)
- Inclusão das diretivas fundamentais `#![no_std]` e `#![no_main]`.
- Implementação de manipulador de pânico `#[panic_handler]` bare-metal com desativação de interrupções (`cli`) e halt da CPU (`hlt`).
- Implementação do símbolo de entrada `_start()`:
  - Leitura da resposta do Limine `FramebufferRequest`.
  - Obtenção do ponteiro bruto do buffer de pixels (`*mut u32`).
  - Renderização de padrão visual de teste e mensagem de identificação `"IA-OS v0.1.0-alpha.1"`.

#### 4. Ferramentas de Build e Emulação
- Criação de `build_and_run.sh` automatizando:
  - Compilação via Cargo.
  - Obtenção dos binários UEFI do Limine.
  - Criação da imagem de disco/ISO bootável com suporte UEFI.
  - Execução via `qemu-system-x86_64` com aceleração (KVM quando disponível) e firmware OVMF.
